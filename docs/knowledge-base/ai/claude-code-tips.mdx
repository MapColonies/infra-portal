# 💡 Claude Code Tips

## 🩺 `/checkup`

Available from v2.1.205; it is the upgraded `/doctor`. It:

- removes unused skills, MCPs and plugins to save context
- removes duplicate content between your personal and project CLAUDE.md
- turns off slow hooks
- updates Claude Code
- enables auto mode
- pre-approves read-only commands you often deny

It asks before every change.

## ⚙️ Settings

- **Too talkative?** `/config` → _Output style_ → **Concise**.
- **Check or switch the model:** `/model`. New models appear when you open a new session.
