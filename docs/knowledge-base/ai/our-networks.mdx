# 🛰️ AI Tools on Our Networks

## 🔒 TS Network

From the Operational Cloud developer community:

- **Nemo**: a ChatGPT-style chat on the TS Network, based on Qwen. It is connected to the TS search engine and can integrate with GitLab. Ask it how to install or connect to things instead of searching for them.
- **Coding tools** (for bug fixes and helm chart changes on the network):
  - **Kilo**: an IDE extension (VS Code)
  - **Opencode**: an autonomous coding agent in the terminal
  - **Claude Code**, running on a Qwen model
- **DevSpace → AI Space**: guides and a marketplace for skills and MCPs.
- **Ray**: the supported installer on the TS Network. Installs and configures many tools with one terminal command.
- **Agents in production**: **Dify** and **Langfuse** (TBD). Use them to build workflow-based agents connected to the relevant knowledge base.
  - An agent for the MapColonies developer portal is in progress.
  - An agent for the MapColonies playground is in progress.

## 🧑‍💻 Development Network: GitHub Copilot

- You request a Copilot license on the internet network through [ServiceNow](https://snowcloud.service-now.com/rsp?id=order_item&table=sc_cat_item_producer&sys_id=4a768974c3fdf6106ab0fb4ce001316c). The deadline is the end of each month for the following month's licenses. Tell team infra once you've submitted it.
- Pick the model that fits the task instead of always using the most expensive one. See the [Copilot models and pricing table](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing).
